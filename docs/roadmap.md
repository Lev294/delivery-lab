# Интенсив: ориентир три дня

План от 2026-09-17: примерно до 2026-09-20, без фиксированного часа дедлайна.
Ученик выделяет 7–8 часов в день, всего 21–24 часа. Самостоятельная реализация наставника
не входит в эти часы. Глубокое освоение всех тем за этот срок не обещается.

| Блок | Реализация | Практика ученика |
| --- | --- | --- |
| День 1 | Заказ и резерв в транзакции, PostgreSQL, Compose, тесты, CI, GitHub | HTTP, путь данных, SQL, commit/rollback, повторы, сохранность |
| День 2 | Inventory, gRPC с дедлайном, два экземпляра Orders, L7 и отдельный L4-профиль | Неизвестный исход вызова, идемпотентность, L3/L4/L7, отказ экземпляра |
| День 3 | Physical streaming replica, WebSocket, отказы, итоговая проверка | Задержка чтения, переподключение, пробная защита и устранение пробелов |

День 3 сохраняет время на защиту. При задержках незавершённые цели отмечаются явно;
срок — ориентир, не гарантия готовности. Необязательные бизнес-функции не добавляем.

Объём: один SKU, переход `reserved → completed`. Без отмен, оплаты, каталога, пользователей,
брокера, Kubernetes, облачного деплоя и полноценного фронтенда. Маленький WebSocket-клиент
допустим. Один балансировщик в двух режимах. Репликация должна быть настоящей.

## Учебный цикл

Теория → схема проекта → важный код/конфигурация → прогноз ученика → команды и наблюдения
→ разбор → изменённый сценарий. Ответы не выдаются до попытки. При ошибке — объяснение
недостающего принципа и повторная проверка. Независимая реализация продолжается без
ожидания каждого учебного ответа.

Технический статус — [verification.md](verification.md). Понимание и личные гипотезы —
Obsidian вне публичного репозитория. Для завершения нужны запуск из чистой копии и защита:
схема, путь заказа, назначение компонентов, балансировка, репликация, отказы, ограничения.
